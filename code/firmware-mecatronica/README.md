# Firmware y Control (Mecatrónica)

Espacio destinado al firmware y control electromecánico del sistema SOFIA:
- Código en C++/Arduino/ESP-IDF para el microcontrolador **ESP32-C3 Super Mini**.
- Control PWM y configuración de registros de los drivers **PCA9685** (I2C).
- Comunicación serial entre módulos sobre el bus **RS-485 / Modbus**.
- Control y calibración de los servomotores **TowerPro MG90S**.
