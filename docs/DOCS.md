# Documentación del Proyecto SOFIA

Este directorio centraliza todos los materiales de referencia, guías académicas, datos experimentales y especificaciones del proyecto:

## Estructura

- **[class-slides/](class-slides/)**: Presentaciones y material técnico de las sesiones de clase LabDST (10 presentaciones + Guía de estudio).
- **[experimental-data/](experimental-data/)**: Registros y bitácoras de pruebas experimentales:
  - `servomotor_pruebas_caracterizacion.xlsx`: Mediciones experimentales de ángulo y tiempo de respuesta de servomotores MG90S (2,300+ muestras).
- **[catalog/](catalog/)**: *Catálogo de entregables documentales.pdf*.
- **[prototype-cad/](prototype-cad/)**: Planos y especificaciones del prototipo demostrador (*Sofia003-E001-04*).
- **[ESTANDAR_COMUNICACION_PC_ESP32.md](ESTANDAR_COMUNICACION_PC_ESP32.md)**: Estándar formal del protocolo de comunicación inalámbrica PC $\leftrightarrow$ ESP32 (tramas, comandos, errores y ACKs).
- **[ARQUITECTURA_Y_WIREFRAMES_GUI.md](ARQUITECTURA_Y_WIREFRAMES_GUI.md)**: Arquitectura, wireframes, flujo de interacción y justificación técnica de la GUI (PySide6).
- **[REGLAS_GESTOS_Y_METRICAS.md](REGLAS_GESTOS_Y_METRICAS.md)**: Repertorio de 7 posturas, lógica de detección y evaluación de latencia/FPS.
